# Hassassin Mechatronics

Open-source ecosystem for designing mechatronic products in one project:
mechanical CAD, electronics (schematic → PCB → fabrication), embedded firmware,
simulation, and robotics — guided by AI so that non-experts can build real things too.

> Status: planning. The design documents are in [`docs/`](docs/README.md).
> Guidance for contributors and AI agents: [`AGENTS.md`](AGENTS.md).
